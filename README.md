# 🎮 Neon Tamagotchi

Виртуальный питомец в стиле "Dark Neon Cartoon" на React.

## ✨ Фичи

- 🥚 **Создание питомца** — 18 видов с редкостями 1★–5★
- 🐾 **Профиль питомца** — статы, эволюция, скины
- 🎮 **Мини-игры** — Match-3, «Поймай еду»
- ⚔️ **PvP арена** — 4 локации, ульта, анимации боя
- 🏆 **Лиги** — LP-очки, лидерборд, награды
- 🎁 **Магазин** — яйца, еда, скины, бусты
- ⚙️ **Настройки** — музыка, звук, сброс прогресса
- ❤️ **Поддержка автора** — СБП перевод

## 🚀 Запуск

```bash
npm install
npm start
